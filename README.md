## Tech Stack
- Vanilla HTML5, CSS3, and JavaScript (no build step, no external APIs)
- Fully responsive, semantic HTML, accessible (skip link, ARIA, focus states)
- SEO meta tags, Open Graph / Twitter cards, and LocalBusiness JSON-LD

## Structure
```
index.html          # Single-page site (hero, about, services, why us, testimonials, contact)
css/styles.css      # All styles
js/main.js          # Mobile nav, smooth scrolling, form validation
favicon.svg         # Favicon
assets/img/         # Image assets
```

## Running Locally
Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080.
